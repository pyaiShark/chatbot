Build an Agent: starter code

  ai.py        Paste your key here, and write call_gpt in milestone 1.
  main.py      Paste your finished Chatbot over this in milestone 1.
  notopenai/   The library that talks to the AI model. Don't edit it.

To open it, choose File > Open Folder in VS Code (File > Open on a Mac)
and pick this folder, the one that holds ai.py and main.py.

The handout is at codeinplace.stanford.edu/cipx/build-an-agent
